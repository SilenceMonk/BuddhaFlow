# BuddhaFlow - 心流番茄钟

一个创新的番茄钟应用，专注于顺应自然的心流状态，而非强制中断。

## 核心理念

传统番茄钟使用倒计时（如25分钟），会强制中断可能持续更长时间的专注状态。BuddhaFlow采用**正向计时**，让你在心流中保持专注，自然地积累休息时间。

## 核心特性

### 1. 正向计时专注
- 不限制专注时长，让心流自然延续
- 实时显示当前专注时间
- 可随时暂停或结束当前专注会话

### 2. 智能休息时间累积
- **休息时间 = 专注时间 × 休息比例**
- 最少累积5分钟才能开始休息
- 休息时会消耗累积的休息时间
- 可随时结束休息继续专注

### 3. 动态休息比例
- 基础比例：20%（专注1小时 = 12分钟休息）
- 随专注时间增加，比例逐渐提高（最高50%）
- 反映真实的疲劳恢复需求：专注越久，需要更多休息

### 4. 数据可视化

#### 过去7天趋势图
- 柱状图显示每天的总专注时间
- 帮助跟踪近期专注习惯

#### 24小时效率热力图
- 可视化展示一天中不同时段的专注表现
- 热力图颜色越深 = 该时段专注时间越长
- 帮助找出最高效的时段

## 使用方法

### 开始使用

1. 在浏览器中打开 `index.html`
2. 点击"开始专注"按钮进入专注模式
3. 专注时间会正向计时，同时累积休息时间

### 专注阶段

- 当前会话专注时间实时显示
- 休息时间累积显示（需≥5分钟才能休息）
- 休息比例实时更新
- 可随时暂停或重置

### 休息阶段

- 累积休息时间≥5分钟时，"开始休息"按钮激活
- 点击开始休息，计时器切换为休息模式
- 休息时间会逐渐消耗累积的休息额度
- 可随时结束休息，继续专注

### 数据统计

- 实时查看今日和本周总专注时间
- 查看过去7天的专注趋势
- 分析24小时效率分布，找出最佳时段

## 技术实现

- 纯前端单页应用（HTML + CSS + JavaScript）
- 使用 localStorage 本地存储数据
- 响应式设计，支持移动端
- 无需服务器，可离线使用

## 数据隐私

所有数据存储在浏览器本地，不会上传到任何服务器。

## 休息比例算法

```javascript
基础比例 = 0.2 (20%)
最大比例 = 0.5 (50%)
比例增长 = 每小时累积休息时间增加5%的比例

当前比例 = 0.2 + min(0.3, 累积休息小时数 × 0.05)
```

例如：
- 专注1小时 → 比例20% → 可休息12分钟
- 专注2小时 → 比例25% → 可休息30分钟
- 专注6小时 → 比例50% → 可休息3小时

## 设计哲学

**顺应自然节奏**：不强制打断心流，而是让专注和休息自然过渡。

**科学休息分配**：专注时间越长，疲劳度越高，需要更高的休息比例来恢复。

**数据驱动优化**：通过可视化历史数据，帮助找出最高效的工作时段。
