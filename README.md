# BuddhaFlow - 心流番茄钟

一个创新的番茄钟应用，专注于顺应自然的心流状态，而非强制中断。

## 核心理念

传统番茄钟使用倒计时（如25分钟），会强制中断可能持续更长时间的专注状态。BuddhaFlow采用**正向计时**，让你在心流中保持专注，自然地积累休息时间。

## 核心特性

### 1. 正向计时专注
- 不限制专注时长，让心流自然延续
- 实时显示当前专注时间
- 可随时暂停或结束当前专注会话

### 2. 平方模型休息时间
- **休息时间 ∝ 专注时间²**
- 基准：专注60分钟 → 赚10分钟休息
- 具体示例：
  - 专注30分钟 → 2.5分钟休息
  - 专注60分钟 → 10分钟休息
  - 专注90分钟 → 22.5分钟休息
  - 专注120分钟 → 40分钟休息
- 最少累积5分钟才能开始休息
- 休息时会消耗累积的休息时间
- 多次专注会话的休息时间会累积

### 3. 科学的疲劳模型
- 平方关系反映真实的疲劳累积规律
- 专注时间越长，疲劳加速累积，需要更多休息
- 有效休息率随专注时间增长而提升
- 鼓励短暂休息后继续专注，保持长期专注习惯

### 4. 数据可视化

#### 过去7天趋势图
- 柱状图显示每天的总专注时间
- 帮助跟踪近期专注习惯

#### 24小时效率热力图
- 可视化展示一天中不同时段的专注表现
- 热力图颜色越深 = 该时段专注时间越长
- 帮助找出最高效的时段

## 使用方法

### 开始使用

1. 在浏览器中打开 `index.html`
2. 点击"开始专注"按钮进入专注模式
3. 专注时间会正向计时，同时累积休息时间

### 专注阶段

- 当前会话专注时间实时显示
- 休息时间基于平方模型实时累积
- 有效休息率随专注时间动态增长
- 可随时暂停或重置

### 休息阶段

- 累积休息时间≥5分钟时，"开始休息"按钮激活
- 点击开始休息，计时器切换为休息模式
- 休息时间会逐渐消耗累积的休息额度
- 可随时结束休息，继续专注

### 数据统计

- 实时查看今日和本周总专注时间
- 查看过去7天的专注趋势
- 分析24小时效率分布，找出最佳时段

## 技术实现

- 纯前端单页应用（HTML + CSS + JavaScript）
- 使用 localStorage 本地存储数据
- 响应式设计，支持移动端
- 无需服务器，可离线使用

## 数据隐私

所有数据存储在浏览器本地，不会上传到任何服务器。

## 平方模型算法

```javascript
// 休息时间与专注时间的平方成正比
休息时间（秒） = k × (专注时间秒)²

// 系数k的计算（基于基准：60分钟专注 = 10分钟休息）
k = 600 / (3600²) ≈ 0.0000463

// 实际计算示例
专注30分钟(1800秒) → 休息 = 0.0000463 × 1800² ≈ 150秒 (2.5分钟)
专注60分钟(3600秒) → 休息 = 0.0000463 × 3600² = 600秒 (10分钟)
专注90分钟(5400秒) → 休息 = 0.0000463 × 5400² ≈ 1350秒 (22.5分钟)
专注120分钟(7200秒) → 休息 = 0.0000463 × 7200² ≈ 2400秒 (40分钟)
```

### 有效休息率计算

```javascript
有效休息率 = 休息时间 / 专注时间 = k × 专注时间

专注30分钟 → 有效休息率 ≈ 8.3%
专注60分钟 → 有效休息率 ≈ 16.7%
专注90分钟 → 有效休息率 = 25%
专注120分钟 → 有效休息率 ≈ 33.3%
```

可以看到，专注时间越长，有效休息率越高，反映了疲劳的非线性累积特性。

## 设计哲学

**顺应自然节奏**：不强制打断心流，而是让专注和休息自然过渡。

**科学疲劳模型**：采用平方模型反映疲劳的非线性累积规律 - 专注时间越长，疲劳加速增长，需要的休息时间呈平方级增加。

**数据驱动优化**：通过可视化历史数据，帮助找出最高效的工作时段。

**长期专注激励**：休息时间可跨会话累积，鼓励保持持续的专注习惯。
