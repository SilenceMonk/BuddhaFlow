# BuddhaFlow - 心流番茄钟

一个创新的番茄钟应用，专注于顺应自然的心流状态，而非强制中断。

## 核心理念

传统番茄钟使用倒计时（如25分钟），会强制中断可能持续更长时间的专注状态。BuddhaFlow采用**正向计时**，让你在心流中保持专注，自然地积累休息时间。

## 核心特性

### 1. 正向计时专注
- 不限制专注时长，让心流自然延续
- 实时显示当前专注时间
- 可随时暂停或结束当前专注会话

### 2. 平方模型休息时间
- **休息时间（分钟） = 3 + 0.004 × (专注时间分钟)²**
- 基础休息：3分钟 + 平方增长部分
- 具体示例：
  - 专注30分钟 → 6.6分钟休息（有效休息率 22%）
  - 专注60分钟 → 17.4分钟休息（有效休息率 29%）
  - 专注90分钟 → 35.4分钟休息（有效休息率 39%）
  - 专注120分钟 → 60.6分钟休息（有效休息率 50.5%）
- 最少累积5分钟才能开始休息
- 休息时会消耗累积的休息时间
- 多次专注会话的休息时间会累积

### 3. 科学的疲劳模型
- 平方关系反映真实的疲劳累积规律
- 专注时间越长，疲劳加速累积，需要更多休息
- 有效休息率随专注时间增长而提升
- 鼓励短暂休息后继续专注，保持长期专注习惯

### 4. 数据可视化

#### 过去7天趋势图
- 柱状图显示每天的总专注时间
- 帮助跟踪近期专注习惯

#### 24小时效率热力图
- 可视化展示一天中不同时段的专注表现
- 热力图颜色越深 = 该时段专注时间越长
- 帮助找出最高效的时段

## 使用方法

### 开始使用

1. 在浏览器中打开 `index.html`
2. 点击"开始专注"按钮进入专注模式
3. 专注时间会正向计时，同时累积休息时间

### 专注阶段

- 当前会话专注时间实时显示
- 休息时间基于平方模型实时累积
- 有效休息率随专注时间动态增长
- 可随时暂停或重置

### 休息阶段

- 累积休息时间≥5分钟时，"开始休息"按钮激活
- 点击开始休息，计时器切换为休息模式
- 休息时间会逐渐消耗累积的休息额度
- 可随时结束休息，继续专注

### 数据统计

- 实时查看今日和本周总专注时间
- 查看过去7天的专注趋势
- 分析24小时效率分布，找出最佳时段

## 技术实现

- 纯前端单页应用（HTML + CSS + JavaScript）
- 使用 localStorage 本地存储数据
- 响应式设计，支持移动端
- 无需服务器，可离线使用

## 数据隐私

所有数据存储在浏览器本地，不会上传到任何服务器。

## 平方模型算法

```javascript
// 核心公式
休息时间（分钟） = 3 + 0.004 × (专注时间分钟)²

// 实际计算示例
专注30分钟 → 休息 = 3 + 0.004 × 30² = 3 + 0.004 × 900 = 3 + 3.6 = 6.6分钟
专注60分钟 → 休息 = 3 + 0.004 × 60² = 3 + 0.004 × 3600 = 3 + 14.4 = 17.4分钟
专注90分钟 → 休息 = 3 + 0.004 × 90² = 3 + 0.004 × 8100 = 3 + 32.4 = 35.4分钟
专注120分钟 → 休息 = 3 + 0.004 × 120² = 3 + 0.004 × 14400 = 3 + 57.6 = 60.6分钟
```

### 有效休息率计算

```javascript
有效休息率 = 休息时间 / 专注时间

专注30分钟 → 有效休息率 = 6.6 / 30 = 22%
专注60分钟 → 有效休息率 = 17.4 / 60 = 29%
专注90分钟 → 有效休息率 = 35.4 / 90 = 39.3%
专注120分钟 → 有效休息率 = 60.6 / 120 = 50.5%
```

### 反向计算（还需专注多久）

```javascript
// 已知：当前专注时间 t1，需要达到的休息时间 target
// 求：还需专注多久

// 由 target = 3 + 0.004 × t2²
// 得 t2² = (target - 3) / 0.004
// 得 t2 = sqrt((target - 3) / 0.004)
// 还需专注 = t2 - t1

例如：当前专注20分钟（已赚4.6分钟），要达到5分钟门槛
target = 5分钟
t2 = sqrt((5 - 3) / 0.004) = sqrt(500) ≈ 22.36分钟
还需专注 = 22.36 - 20 = 2.36分钟
```

可以看到，专注时间越长，有效休息率越高，反映了疲劳的非线性累积特性。

## 设计哲学

**顺应自然节奏**：不强制打断心流，而是让专注和休息自然过渡。

**科学疲劳模型**：采用 `3 + 0.004t²` 公式
- 基础休息（3分钟）：保证短时专注也有基本恢复时间
- 平方增长部分（0.004t²）：反映疲劳的加速累积特性
- 有效休息率从22%增长到50%+，匹配真实疲劳曲线

**数据驱动优化**：通过可视化历史数据，帮助找出最高效的工作时段。

**长期专注激励**：休息时间可跨会话累积，鼓励保持持续的专注习惯。
